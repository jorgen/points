# Public C headers parsed into the binding IR, in umbrella-include order.
# Each line is relative to src/; the first path component is the module and
# also the include root (so "common/dew/common/error.h" is included as
# <dew/common/error.h> with -I src/common).
#
# The order matters: headers are not standalone-parseable
#   - aabb.h before camera.h (camera.h uses struct dew_aabb_t*)
#   - camera.h before renderer.h (renderer.h uses struct dew_camera_t* without
#     declaring it; camera.h provides the file-scope forward declaration)
#   - data_source.h before renderer.h (renderer.h passes dew_data_source_t by value)
#
# Deliberately excluded, one '!' line each so a forgotten header is
# distinguishable from an intentional omission (parse_headers.py audits this):
